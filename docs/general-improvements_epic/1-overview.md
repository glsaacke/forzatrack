# Goal

The goal of this epic is to improve the site architecture, infrastructure, and general functionality. Rather than focus on user facing features, the intent will be to improve the development experience and help transition the site from a personal tool to something worthy of being used by external users.

# Basic Requirements

- Login system will need to be overhauled to use proper hashing and general authentication standards
- Custom DotEnv and api key middleware need to be reviewed
- EF Core needs to be implemented
- Any other suggestions the AI has will be considered

# Assumptions

- The site will be made public to other users
